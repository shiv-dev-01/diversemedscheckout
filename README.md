# Diverse Meds Checkout

Checkout for **Diverse Meds**. Shoppers choose a treatment, enter contact and shipping details, apply a coupon when one is offered, pay, and reach the order confirmation page.

The repository name is `diversemedscheckout` because this project is the checkout code for Diverse Meds.

## Stack

- React
- Create React App
- React Router
- Axios
- Tailwind CSS
- styled-components
- React Hot Toast

## Requirements

- Node.js 18 or later
- npm

## Run locally

```bash
git clone https://github.com/shiv-dev-01/diversemedscheckout.git
cd diversemedscheckout
cd diversemeds_checkout-main
npm install
npm start
```

The dev server opens at http://localhost:3000.

## Scripts

| Command | What it runs |
| --- | --- |
| `npm run start` | `react-scripts start` |
| `npm run build` | `react-scripts build` |
| `npm run test` | `react-scripts test` |
| `npm run eject` | `react-scripts eject` |

## Configuration

API hosts and site settings are in `diversemeds_checkout-main\src\utils\Constant.js`.
Files named `.env` stay on your machine and are not part of this repository. Use `.env.example` when the project includes one.
